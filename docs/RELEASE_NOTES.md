# v1.1.2 版本说明

本版包含扫描回访、重叠卡片及首屏采集保护修复，管理员启动、表格预览与 Excel 导出改进，详见 CHANGELOG.md。

## 安装与升级

- 下载 Windows x64 ZIP 及同名 `.sha256`，核对校验值后解压到普通用户可写目录，运行 EXE；Windows 会请求管理员授权。
- 默认普通屏幕采集；游戏客户区必须完整位于同一屏幕内、无遮挡且不最小化。不要启用实验环境变量来绕过此要求。
- “初始化档案”为原“识别全部UID”的新名称，保留完整 UID 补录和复核功能；日常可先快速扫描。
- 升级前正常关闭软件并备份整个 data 及 config.json；新程序文件可以替换，私人数据不要上传。需要保留旧版时，使用独立目录。
- 独立源码包不包含 Python 环境、个人设置、数据库或截图。源码运行与便携 EXE 的安装方法不同。

## 验证范围

- 此前同等扫描功能代码在一台非干净 Windows 11 电脑完成普通模式 69/69 位、14 屏扫描，成功提交，并独立区分一组同名好友。原始记录见 VALIDATION-2026-11-12.md。
- v1.1.2 自动回归 933 项：828 通过、105 跳过、0 失败。新增打包测试确认公开验证文档随包提供，私有报告仍被排除。
- 新 EXE 构建成功；静态检查确认 x64 PE、requireAdministrator 清单、内嵌版本 1.1.2、3 个 OCR ONNX 模型及关键 Python/Qt/ONNX 原生文件。Windows ZIP 包含 58 份依赖许可文件，源码包附逐文件 SHA256 清单。
- 新 EXE 已实际启动并出现主窗口，创建独立配置、数据和日志目录；首次正常关闭由维护者确认，启动日志未发现 DLL 导入错误。
- 桌面工具无法激活测试窗口，重新打开需要维护者确认 UAC。按维护者要求，后续界面收尾交由人工；新 EXE 的模型初始化、OCR 调用、设置保存与重开读取尚未核验，不记为通过。此前源码功能测试不能替代这些新 EXE 项目。
- 构建警告中的 TensorRT 推理后端及 ONNX 量化工具未安装；它们不是本版默认 CPU/ONNX Runtime 推理路径，未为消除警告额外安装依赖。
- 本地开发机上的 EXE 验证不代表干净 Windows 10/11、跨电脑或首次离线运行验收。
- T01 后页身份冲突返回历史行的实机路径、完整 UID 初始化、长期监测、真实 MySQL 服务及遮挡/最小化后的完整扫描仍未全面验证。
- OCR 结果仍需核对。既有扫描有 2 个昵称保留图片待人工校准及 1 条签名单字符差异未对照确认，不承诺全部字段准确。

本次不覆盖原 v1.1.1 Release 或其文件；每个新 ZIP 均附独立 SHA256。
