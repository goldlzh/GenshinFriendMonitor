# 指定窗口采集与管理员启动

用户授权：尝试实现遮挡下采集指定游戏窗口；软件正常启动必须请求管理员权限，非管理员进入时明显提醒。

## 选择与范围

采用已安装 Qt 6.11.2 的 QWindowCapture/QVideoSink，按精确 HWND 创建 QCapturableWindow，首选 Windows WGC/UWP。复用现有 ShellExecuteW(runas) 提权代码。相比新增 WinRT/Rust/Python 采集依赖，此方案可在当前环境直接开发；桌面矩形采集仅保留给明确选择的手动区域。截图不使用游戏内注入。

Qt 采集对象只在 Qt 应用主线程使用；扫描线程通过请求代理取得一次新的 RGB 帧。每次请求新建会话，避免把上次目标/旧画面误作当前截图。客户端区域根据窗口几何映射裁剪；窗口关闭、最小化、移动/尺寸变化、黑帧或超时必须显式失败。窗口采集失败不默默回退 mss。

实测修订：Qt 6.11.2 可能在窗口外框尺寸与 WGC ContentSize 不一致时重建 frame pool 并丢弃首帧，纯静态窗口随后不再产帧。每个会话仅在 100/400/800ms 最多三次异步 InvalidateRect 请求目标重绘；校验窗口仍有效、可见、非最小化及 PID/TID 一致，结束即取消剩余定时器。不激活、不改变几何、不发送键鼠或同步 UpdateWindow。静态/动态合成遮挡对照已验证此修正；原失败证据保留。

现有截图矩形 API 保留，通过线程局部的目标窗口作用域选后端，便于现有离线回放继续使用隔离输入。身份、昵称 OCR、滚动匹配、提交条件和键鼠前台保护不放宽。采集可在遮挡下工作不意味着可后台操作游戏。

审查修订：前台游戏仍可能被不激活的置顶窗遮挡，该遮挡窗会接收全局鼠标事件。点击、拖动和系统滚轮除前台检查外，还须检查实际鼠标点 WindowFromPoint 的 GA_ROOT 为指定游戏 HWND；移动后和拖动中复核，异常/遮挡明确停止。owned popup 不按 ROOTOWNER 放行，鼠标释放必须在 finally 无条件执行。命中失败不通过 PostMessage 绕过继续。保留明确的手动区域语义与原有安全回退，仅新增命中保护，不改坐标或滚动算法。

管理员启动在加载配置/主窗口前检查当前令牌，非管理员通过 UAC 重启相同软件并保留参数；取消/失败显示原因并退出。用重试标记避免无限提权。EXE 构建 manifest 要求管理员。主窗口被其他入口直接创建且令牌不足时显示明显提醒并阻止游戏扫描。无权限时不自行修改系统策略或输入凭据。

## 验证与交付

先以模拟 Qt/窗口几何和令牌/UAC 测试建立失败用例，再实现。覆盖新帧、RGB 内存所有权、客户端裁剪、遮挡采集路由、并发/超时/关闭、无桌面回退、提权成功/取消/失败/重试、非管理员提醒和扫描保护。保留原有扫描/数据库异常保护测试。

桌面验证交给 GPT-6.1 Terra，只操作独立测试/合成窗口；实际游戏仅做用户授权范围内的只读取帧，不扫描、不发游戏输入，不展示或上传未经脱敏截图。真实游戏无法验证时明确标记未测。独立测试副本保留旧资料，不覆盖发布包，不推送或发布。
